## How to read the matrix

**No new Apple silicon required for an outcome** is different from **no hardware required**, **no platform restrictions**, and **already working**. A phone microphone/camera, existing wearable, or connected peripheral supplies real observations; the Mac mini can store context, execute permitted tools, schedule work and route inference to local or chosen external models. The Mac mini does not need to contain the camera. New hardware is genuinely necessary only for reproducing the named physical properties or hardware-enforced mechanism; alternative existing hardware may already provide adequate inputs.

A remote model cannot add optics, sensor measurements, battery capacity, secure-sensor attestation, OS entitlements or carrier agreements. A more capable model may improve an assistant outcome, but superiority requires comparative task-success, latency, quality, privacy and cost measurements. Apple describes cloud inference too (04:22–05:48); Gombwe's distinction is owned context, model/provider choice and host portability. Local hosting does not make external model calls private from the selected provider.

**Latest user scope:** the matrix measures every gap; the team must not try to solve every gap. **BUILD** covers practical host AI; **BUILD_PARTIAL** covers only the straightforward host/input flow, with original mechanism limitations recorded; **GAP_ONLY** means no coding, research, clinical validation, new peripheral integration or workaround project; **CONTEXT** records commercial/release/demo context. Dedicated health work is gap-only. These are assignments, not claims of implementation. Retaining compatible Apple hardware does not require building every Apple-device-specific surface.

## Release context

The source describes iPhone 18 Pro/Pro Max, AirPods 5, Watch Series 12/Ultra 4 and iPhone Duo, plus iOS 27 and Apple Intelligence changes. It does not announce a separate base iPhone 18 in the supplied text. OS/16-language Intelligence releases are stated for this month; Siri AI is English beta with French, Japanese, Korean, Portuguese and Spanish in October. Server limits and higher iCloud+ allowances are described. New Health is later this year, US English first; Live Rewind/Recap are later-year English betas requiring Siri AI. Pencil support is later this year. Pro/Max preorders Sept 12 and availability Sept 18; AirPods/Watch event-day preorders and Sept 18 availability; Duo preorders Oct 16 and availability Oct 23. iPhone Handoff names T-Mobile/Telekom Germany initially and Verizon/EE by year end. These are transcript claims, not a claim that all features are shipping now or that exact older-device support has been established.

Transcription uncertainties remain: “scenes ID” image standard, “core AI” SDK name and “H20 Pro” in Smart Take. Do not silently turn these into verified API names. Ads/opening film/music are not separate launches; the Watch ad at 50:33 repeats sensing/readiness themes, and the 51:22 latitude line does not establish a separately specified new location feature.
